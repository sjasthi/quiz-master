📖 Welcome to Python Lists!

🎯 What is a List?

A list is like a container that can hold multiple items in order. Think of it like a shopping cart 🛒 where you can put different items, or a playlist 🎵 where you arrange your favorite songs in a specific order.

# Examples of Lists
fruits = ["apple", "banana", "cherry"]
numbers = [10, 20, 30, 40, 50]
mixed = [1, "hello", 3.14, True]
empty_list = []
💡 Key Points:
  • Lists are created using square brackets [ ]
  • Items are separated by commas
  • Lists can hold any type of data: numbers, strings, even other lists!
  • Items in a list maintain their order
  • Python starts counting from 0 (first item is at position 0)

🔧 Two Ways to Work with Code in Python

This is SUPER IMPORTANT! There are two different ways to call operations in Python, and they look different:

⭐ Way #1: Built-in Functions (like print and input)

These are general-purpose functions that work on their own. You put the data inside the parentheses.

# Built-in Functions - data goes INSIDE parentheses
print("Hello World") # Function name, then (data)
len([1, 2, 3]) # Function name, then (data)
input("Enter name: ") # Function name, then (data)
max([5, 2, 8]) # Function name, then (data)
📌 Pattern: function_name(data)

⭐ Way #2: List Methods (like .append and .sort)

These are special operations that belong to lists. You start with the list name, then use a dot (.), then the method name. These methods change or work with that specific list.

# List Methods - list name FIRST, then dot, then method
my_list = [1, 2, 3]
my_list.append(4) # list_name.method(data)
my_list.sort() # list_name.method()
my_list.reverse() # list_name.method()
my_list.pop(0) # list_name.method(data)
📌 Pattern: list_name.method_name()

❌ Common Mistakes to Avoid

❌ WRONG - Trying to use list methods like functions:
append(my_list, 5) # ❌ This doesn't work!
sort(my_list) # ❌ This doesn't work!
reverse(my_list) # ❌ This doesn't work!
✅ CORRECT - List methods need the list name first with a dot:
my_list.append(5) # ✅ Correct!
my_list.sort() # ✅ Correct!
my_list.reverse() # ✅ Correct!
❌ WRONG - Trying to use functions like methods:
"Hello".print() # ❌ This doesn't work!
my_list.len() # ❌ This doesn't work!
name.input() # ❌ This doesn't work!
✅ CORRECT - Functions take data inside parentheses:
print("Hello") # ✅ Correct!
len(my_list) # ✅ Correct!
input("Enter name: ") # ✅ Correct!

🧠 How to Remember the Difference

🔹 Built-in Functions (print, len, input):

  • Work on ANY type of data (strings, lists, numbers, etc.)
  • Stand alone - don't need a specific object
  • Think: "I want to print something" → print(something)
  • Think: "I want the length of something" → len(something)

🔹 List Methods (.append, .sort, .remove):

  • Only work on lists - they belong to the list object
  • Need a specific list to operate on
  • Think: "I want my list to append something" → my_list.append(something)
  • Think: "I want this list to sort itself" → this_list.sort()

🎓 Quick Reference

📞 Functions
print(data)
len(data)
input(data)
📝 List Methods
list.append()
list.sort()
list.remove()

🎨 Learn List Methods with Shapes!

Welcome! In this playbook, we'll use colorful shapes to understand how Python list methods work. Each shape represents an item in a list: 🔴 Red Circle, 🔵 Blue Square, and 🔺 Orange Triangle.

.append()
📌 Adds an item to the END of the list. Think of it like adding a new friend to the end of a line!
Before:
my_list.append(🔺)
After:
fruits = ["apple", "banana"]
fruits.append("orange")
print(fruits) # ["apple", "banana", "orange"]
.insert()
📍 Inserts an item at a SPECIFIC position. Like cutting in line at position 1!
Before:
my_list.insert(1, 🔺)
After:
colors = ["red", "blue", "blue"]
colors.insert(1, "yellow")
print(colors) # ["red", "yellow", "blue", "blue"]
.pop()
🎈 Removes and returns an item at a specific position (or the last item if no position given).
Before:
my_list.pop(1)
After:
numbers = [10, 20, 30, 40]
removed = numbers.pop(1) # Removes 20
print(numbers) # [10, 30, 40]
print(removed) # 20
.remove()
❌ Removes the FIRST occurrence of a specific value from the list.
Before:
my_list.remove(🔵)
After:
pets = ["cat", "dog", "dog", "bird"]
pets.remove("dog") # Removes first "dog"
print(pets) # ["cat", "dog", "bird"]
.reverse()
🔄 Reverses the order of items in the list. Like reading a word backwards!
Before:
my_list.reverse()
After:
letters = ["A", "B", "C", "D"]
letters.reverse()
print(letters) # ["D", "C", "B", "A"]
.sort()
📊 Sorts the list in ascending order (smallest to largest, or A to Z).
Before:
my_list.sort()
After:
numbers = [5, 2, 8, 1, 9]
numbers.sort()
print(numbers) # [1, 2, 5, 8, 9]
.index()
🔍 Returns the position (index) of the FIRST occurrence of an item.
List:
my_list.index(🔺)
Returns: 2
(Remember: Python counts from 0! So position 2 is the 3rd item)
fruits = ["apple", "banana", "cherry"]
position = fruits.index("cherry")
print(position) # 2
.count()
🔢 Counts how many times an item appears in the list.
List:
my_list.count(🔵)
Returns: 2
(There are 2 blue squares in the list)
scores = [10, 20, 10, 30, 10]
how_many = scores.count(10)
print(how_many) # 3

💻 List Methods with Numbers & Strings

Now let's see how these same methods work with actual numbers and strings in Python! Click the "Run Code" buttons to see the results in action.

.append()
📌 Adds an item to the END of the list
# Example with Numbers
numbers = [10, 20, 30]
print("Before:", numbers)
numbers.append(40)
print("After:", numbers)
# Output:
# Before: [10, 20, 30]
# After: [10, 20, 30, 40]
# Example with Strings
fruits = ["apple", "banana"]
print("Before:", fruits)
fruits.append("cherry")
print("After:", fruits)
# Output:
# Before: ['apple', 'banana']
# After: ['apple', 'banana', 'cherry']
.insert()
📍 Inserts an item at a SPECIFIC position
# Example with Numbers
scores = [85, 90, 95]
print("Before:", scores)
scores.insert(1, 88)
print("After:", scores)
# Output:
# Before: [85, 90, 95]
# After: [85, 88, 90, 95]
# Example with Strings
colors = ["red", "blue"]
print("Before:", colors)
colors.insert(1, "green")
print("After:", colors)
# Output:
# Before: ['red', 'blue']
# After: ['red', 'green', 'blue']
.pop()
🎈 Removes and returns an item at a specific position
# Example with Numbers
numbers = [100, 200, 300, 400]
print("Before:", numbers)
removed = numbers.pop(1)
print("After:", numbers)
print("Removed item:", removed)
# Output:
# Before: [100, 200, 300, 400]
# After: [100, 300, 400]
# Removed item: 200
# Example with Strings
animals = ["cat", "dog", "bird", "fish"]
print("Before:", animals)
removed = animals.pop(2)
print("After:", animals)
print("Removed item:", removed)
# Output:
# Before: ['cat', 'dog', 'bird', 'fish']
# After: ['cat', 'dog', 'fish']
# Removed item: bird
.remove()
❌ Removes the FIRST occurrence of a specific value
# Example with Numbers
numbers = [5, 10, 15, 10, 20]
print("Before:", numbers)
numbers.remove(10)
print("After:", numbers)
# Output:
# Before: [5, 10, 15, 10, 20]
# After: [5, 15, 10, 20]
# Example with Strings
pets = ["cat", "dog", "cat", "bird"]
print("Before:", pets)
pets.remove("cat")
print("After:", pets)
# Output:
# Before: ['cat', 'dog', 'cat', 'bird']
# After: ['dog', 'cat', 'bird']
.reverse()
🔄 Reverses the order of items in the list
# Example with Numbers
numbers = [1, 2, 3, 4, 5]
print("Before:", numbers)
numbers.reverse()
print("After:", numbers)
# Output:
# Before: [1, 2, 3, 4, 5]
# After: [5, 4, 3, 2, 1]
# Example with Strings
letters = ["A", "B", "C", "D"]
print("Before:", letters)
letters.reverse()
print("After:", letters)
# Output:
# Before: ['A', 'B', 'C', 'D']
# After: ['D', 'C', 'B', 'A']
.sort()
📊 Sorts the list in ascending order (smallest to largest, or A to Z)
# Example with Numbers
numbers = [45, 12, 89, 23, 5]
print("Before:", numbers)
numbers.sort()
print("After:", numbers)
# Output:
# Before: [45, 12, 89, 23, 5]
# After: [5, 12, 23, 45, 89]
# Example with Strings
names = ["Zoe", "Alice", "Mike", "Bob"]
print("Before:", names)
names.sort()
print("After:", names)
# Output:
# Before: ['Zoe', 'Alice', 'Mike', 'Bob']
# After: ['Alice', 'Bob', 'Mike', 'Zoe']
.index()
🔍 Returns the position (index) of the FIRST occurrence of an item
# Example with Numbers
numbers = [10, 20, 30, 40, 50]
position = numbers.index(30)
print("List:", numbers)
print("Position of 30:", position)
# Output:
# List: [10, 20, 30, 40, 50]
# Position of 30: 2
# Example with Strings
fruits = ["apple", "banana", "cherry", "date"]
position = fruits.index("cherry")
print("List:", fruits)
print("Position of 'cherry':", position)
# Output:
# List: ['apple', 'banana', 'cherry', 'date']
# Position of 'cherry': 2
.count()
🔢 Counts how many times an item appears in the list
# Example with Numbers
numbers = [5, 10, 5, 20, 5, 30]
count = numbers.count(5)
print("List:", numbers)
print("Count of 5:", count)
# Output:
# List: [5, 10, 5, 20, 5, 30]
# Count of 5: 3
# Example with Strings
colors = ["red", "blue", "red", "green", "red"]
count = colors.count("red")
print("List:", colors)
print("Count of 'red':", count)
# Output:
# List: ['red', 'blue', 'red', 'green', 'red']
# Count of 'red': 3
